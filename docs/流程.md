# 流程

# 收到客户在媒体中留下的信息（抖音，小红书，视频号）\-\-\-线索

每条线索代表潜在的购车意图。

销售需要把这种潜在的购车意图变成到店购车的订单。

智能客服解决销售的痛点\-工作时间有限，人力成本高，效率低。

采用智能客服实现自动回复客户问题，联系客户（通过企微）引导客户到店提车

主要的业务逻辑上述流程

下面主要的技术方案

视频号抖音小红书收到客户评论或者私信

信息转发给智能客服（暂不考虑实现\-\-调用视频号端接口）客服发消息给客户使用RPA

智能客服收到信息首先进行知识库检索\-\-\-\-\-知识库构建（排序算法，动态更新）

检索时\-\-相似度查询，匹配同时使用（基于热度，语义相似度，关键词匹配，新鲜度排序）

进入

分类分支：

1\.闲聊超过三次请求终止会话不在回复信息

2\.用户询问联系方式公司基本信息（配置在agent配置里面包括打招呼和自我介绍）

3\.用户询问买车事宜可能是具体某款车可能是准备买车不知道买什么而希望有推荐

对于3\-\-\-\-调用知识库查询结果（查询到公司某款车辆的库存和公司车辆相关信息性价比推荐）遇到表述模糊没能直接定位到哪个车品牌的设计的排序算法和关键词提取能最大程度增加命中，然后推荐和引导设计agent发问话术\-了解客户画像地址信息匹配对应的仓点和4s店

给出实拍照片介绍

用户提出到店试车或者买车。或者识别到一些关键词用户可能到店里（比如询问地址了，询问地址要根据客户实际ip去定位距离最近的店）能汇总用户信息通过企微发消息给对应门店销售做进一步线下跟进。
