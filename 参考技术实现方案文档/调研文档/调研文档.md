# 拼多多智能客服（图形化界面）\-\-\-给电商

1. **工具驱动的 Agent 循环**

while loop \< max\_loops:

调 LLM → 返回 tool\_calls？→ 并行执行工具 → 结果回传 → 继续

返回 text？→ 最终回复

这是标准的 ReAct 模式实现，比 Xianyu 的纯 Prompt 方案强。
